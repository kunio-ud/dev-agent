# テスト観点カタログ

## 要件由来

| 入力 | 観点 |
|---|---|
| 業務要件 `BR` | 業務フロー、業務ルール、例外業務、受入、UAT |
| 機能要件 `FR` | 正常系、異常系、入力検証、権限、状態、競合 |
| 非機能要件 `NFR` | 性能、可用性、セキュリティ、運用、監査、移行 |
| 受入条件 `AC` | 合否基準、検収条件、顧客確認観点 |
| 制約 `CON` | 対応ブラウザ、法令、外部サービス制約、運用制約 |

## 基本設計由来

| 入力 | 観点 |
|---|---|
| 画面 `SCR` | 表示、入力、バリデーション、状態、ロール別表示、アクセシビリティ |
| API `API` | リクエスト、レスポンス、認証認可、エラー、互換性、レート制限 |
| DB `TBL` | CRUD、制約、整合性、トランザクション、マイグレーション、検索性能 |
| 処理フロー `FLOW` | 分岐、例外、状態遷移、ロールバック、二重実行 |
| 外部IF `IF` | 送受信、タイムアウト、リトライ、フォーマット不正、責任分界 |
| バッチ `BAT` | 0件、正常終了、部分失敗、再実行、締め時間、監査ログ |

## 実装由来

- 条件分岐
- 例外処理
- 権限チェック
- バリデーション
- DB更新
- 外部API呼び出し
- 時刻依存
- 並行実行
- キャッシュ
- リトライ
- ログ/監査ログ

## 品質観点

| 観点 | 例 |
|---|---|
| 正常系 | 期待される代表ケース |
| 異常系 | 入力不正、権限なし、NotFound、Conflict |
| 境界値 | 0件、1件、上限、日付境界、桁数境界 |
| 状態遷移 | 下書き→承認→確定、再実行不可など |
| データ整合性 | 作成/更新/削除後のDB状態 |
| 冪等性 | 同じ処理を複数回実行しても破綻しない |
| 並行実行 | 同時更新、重複登録、排他制御 |
| 性能 | 応答時間、処理時間、スループット |
| セキュリティ | 認証認可、入力攻撃、情報漏えい |
| 運用 | ログ、監視、通知、障害時復旧 |
