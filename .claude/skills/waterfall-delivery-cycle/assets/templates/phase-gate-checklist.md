# Phase Gate Checklist

## 要件定義完了

- [ ] 目的、スコープ、対象外が明確。
- [ ] BR/FR/NFR/AC/TBD が整理されている。
- [ ] ブロッカーTBDがない。

## 基本設計完了

- [ ] 画面/API/DB/処理フロー/外部IF/バッチの影響が整理されている。
- [ ] 要件IDと設計IDが紐づいている。
- [ ] 実装に必要な未決事項が明確。

## 実装開始可能

- [ ] `CODING_RULES.md` がある、または既存規約が確認されている。
- [ ] 対象リポジトリ、言語、対象レイヤーが明確。
- [ ] セキュリティ、DB破壊、外部IF変更の確認が済んでいる。

## テスト開始可能

- [ ] 実装対象と変更範囲が明確。
- [ ] UT観点またはテスト観点表がある。
- [ ] Must観点が定義されている。

## リリース判定可能

- [ ] Must要件が実装済み。
- [ ] Mustテスト観点が消化済み。
- [ ] 未解決障害と残リスクが整理されている。
- [ ] 切戻し、監視、運用引継ぎが確認されている。
