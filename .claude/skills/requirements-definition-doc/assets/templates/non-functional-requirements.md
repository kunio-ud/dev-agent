## 分類と主要観点

| 分類 | 主要観点 |
|---|---|
| 規模・性能 | 登録ユーザー数、同時接続数、応答時間（95%ile）、スループット、ピーク条件 |
| 可用性・信頼性 | 稼働率/SLA、停止許容時間（RTO/RPO）、バックアップ、冗長化 |
| 拡張性 | ユーザー増加対応、機能追加容易性、スケールアウト/スケールアップ方針 |
| セキュリティ | 認証・認可方式、暗号化（通信・保存）、監査ログ、脆弱性対応方針 |
| 運用・監視 | 監視項目、アラート条件、ログ保持期間、障害対応手順、定期作業 |
| 保守性 | 設定変更容易性、ドキュメント整備、保守体制、テスト自動化方針 |
| 移行性 | 移行方式、並行稼働期間、切戻し条件、移行後検証方法 |
| システム環境・中立性 | 対応OS/ブラウザ、クラウド/オンプレ中立性、外部サービス依存度 |
| 法令・コンプライアンス | 個人情報保護法/GDPR/PCI DSS等の適用、監査対応、データ保持義務 |
